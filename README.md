# Selenium

## Before testing

- create .env file in tests and set url, account and password
- install requirements.txt

## Helpful extension of Chrome

- ranorex selocity

## Testing all

- pytest

## Testing individually

- pytest -m login

## Testing with Firefox

- pytest --browser=firefox

## Headless mode

- pytest --headless

## Export HTML report

- pytest --html=report.html
- pytest --html=report.html --self-contained-html --tb=short
